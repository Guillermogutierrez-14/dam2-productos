GGS

GGS es una empresa dedicada al desarrollo de aplicaciones web y móviles. Trabajamos con Ionic y Angular para crear interfaces modernas que consumen servicios REST y ofrecen una buena experiencia de usuario.

Este proyecto forma parte de la actividad de DAM2 de Desarrollo de Interfaces: una aplicación que muestra un catálogo de productos obtenido desde una API.
